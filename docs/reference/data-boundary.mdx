PreScale's CLI works fully offline. Nothing leaves your machine unless you pass `--upload`,
run `prescale upload`, or use the GitHub Action.

## What an upload contains

The saved run file (`.prescale/runs/<id>.json`), unchanged:

- The verdict: users survived, confidence band, where and why it broke
- Per-stage and per-route timings, error rates and request counts
- The diagnosis and suggested fixes, if you ran `investigate`
- HTTP hygiene findings, if you ran `--audit`
- The target URL and the route paths you tested
- The git commit and branch, and the CLI version

See it for yourself before sending anything:

```bash
prescale upload --dry-run
```

## What never leaves your machine

- Request and response bodies
- Cookies
- Header values you pass with `-H` (auth tokens, Vercel bypass secrets)
- Environment variables
- Anything from your codebase

## Who can see your runs

- Runs are private to your account.
- A run is public only if you **share** it (an unguessable link you can take down) or
  **sign it off**.
- API tokens are stored as hashes; the token itself is shown once.

The CLI, the installer and the GitHub Action are open source:
[github.com/pyjeebz/PreScale](https://github.com/pyjeebz/PreScale).
